## 第二大脑 —— 基于ReAct Agent的智能知识管理助手

### 一、项目概述

"第二大脑"是一个基于大语言模型的智能知识管理Agent，它不仅能存储和检索知识，更能**自主决策、主动推送、发现关联**。与传统笔记工具的被动存储不同，"第二大脑"实现了完整的Agent Loop，能够根据用户意图自动选择工具、执行多步推理、并在适当时机主动行动。

### 二、核心Agent特性

**1. 自主决策能力（Tool Calling）**

系统定义了5个标准化工具：`add_knowledge`（知识入库）、`search_knowledge`（语义搜索）、`manage_knowledge`（笔记管理）、`send_reminder`（复习提醒）、`fetch_web_content`（网页抓取）。当用户输入一句话时，Agent通过LLM的Function Calling能力自主判断应该调用哪个工具。

例如用户说"帮我记一下Redis的LRU算法"，Agent会自动执行以下决策链：
- 判断意图：用户想要保存知识 → 调用`add_knowledge`
- 执行工具：将文本向量化存入Supabase
- 附加操作：自动提取标签、更新遗忘曲线记录

整个过程无需用户指定工具，Agent完全自主完成。

**2. 多步推理能力（ReAct Loop）**

系统实现了完整的ReAct（Reasoning + Acting）循环。以搜索场景为例：

```
用户提问 → Agent思考（需要搜索）→ 调用search_knowledge
→ 观察结果（找到3条笔记）→ Agent思考（需要整理）
→ 生成总结性回答
```

这个循环最多执行5轮，确保Agent能在复杂任务中持续推理直到得出答案。

**3. 记忆能力**

系统实现了两层记忆架构：
- **短期记忆**：维护当前对话历史，支持多轮对话上下文理解
- **长期记忆**：存储用户偏好、关注主题、学习节奏，基于Supabase云端持久化

此外，系统实现了基于SM-2算法的**遗忘曲线记忆**：每条笔记都有记忆保留率指标，Agent能精确追踪用户"快忘了什么"。

### 三、技术架构

```
┌─────────────┐    ┌──────────────────┐    ┌─────────────┐
│   用户界面   │ ←→ │   Agent 核心层    │ ←→ │   存储层     │
│  (Streamlit) │    │                  │    │  (Supabase) │
│             │    │  System Prompt   │    │             │
│  对话交互    │    │  + LLM 推理     │    │  PostgreSQL  │
│  工具可视化  │    │  + Tool Router   │    │  向量检索    │
│  数据面板    │    │  + Agent Loop    │    │  遗忘曲线    │
└─────────────┘    └──────────────────┘    └─────────────┘
```

- **LLM引擎**：DeepSeek API，负责推理和自然语言生成
- **向量数据库**：Supabase pgvector，支持语义相似度搜索
- **前端框架**：Streamlit，支持对话界面和数据可视化
- **云端部署**：Supabase云数据库，支持多设备访问

### 四、创新价值

**1. 从被动工具到主动Agent**

现有笔记工具（Notion、Obsidian）是"你问它答"，而"第二大脑"是"它主动找你"。基于遗忘曲线的主动推送机制，让知识管理从"用户驱动"变成"Agent驱动"。

**2. 语义检索替代关键词搜索**

传统搜索依赖关键词精确匹配，"第二大脑"使用Embedding向量化+余弦相似度，实现真正的语义理解。搜"多线程"能找到"并发编程"的笔记。

**3. 知识关联发现**

Agent能自动发现不同笔记之间的语义关联，主动推送知识洞见——这是传统笔记工具无法实现的。

### 五、应用场景

- **学生党**：课程笔记、考试复习、错题管理
- **开发者**：技术文档、代码片段、架构笔记
- **知识工作者**：会议纪要、行业研究、灵感记录

### 六、总结

"第二大脑"不是另一个笔记应用，而是一个**有记忆、会思考、能主动行动的AI Agent**。它将大语言模型的推理能力与知识管理场景深度结合，展示了Agent技术在日常工具中的落地可能。
